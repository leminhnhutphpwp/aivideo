# Hyper-Surrealism
Photorealistic yet impossible scenes that blend dreamlike elements with cinematic realism. Use this skill to create imagery where crystal mountains reflect aurora, architecture grows like living coral, and whales float through clouds. Emphasize volumetric lighting, caustic refractions, and ultra-detailed textures to make the surreal feel tangible.
